# Pham Hong Hieu (Haven-范鴻孝) | Portfolio (EN / VI / 繁體 / 简体)

**Static website. No Node, npm, hosting package, or compilation required.**

Open `index.html` in Chrome or Edge. Switch language in the header and toggle dark/light theme.

## Technology

HTML5, CSS3, vanilla JavaScript. A local-file-friendly design: `content.js` provides the four language dictionaries; `main.js` manages tabs, modals, scrolling, copy-email, theme and language selection. CSS uses system fonts and requires no external font download.

## What's inside?

- Responsive sections: About, Experience, Projects, Workflow & Stack, Community, Certifications, Contact.
- Four complete content sets: English, Vietnamese, Traditional Chinese, Simplified Chinese.
- Real supplied certificate assets for HackerRank and DataCamp, plus a privacy-safe entry for the Mandarin course.
- Local SQL starter project using **synthetic** CSV data; marked as a starter, not an actual finished work outcome.
- `assets/Pham_Hong_Hieu_CV_DRAFT.pdf`: **review draft**, not an approved CV.

## Publish

Create a GitHub repository and upload the *contents of this folder* with `index.html` at repository root. On Vercel select the repository, Framework = Other and Deploy. No environment variables or npm install necessary.

Please read `START_HERE_VI.txt` for a beginner-friendly Vietnamese walk-through and `docs/CACH_CAP_NHAT_WEBSITE_VI.md` to edit content.
