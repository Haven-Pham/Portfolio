# Synthetic Educational Datasets

This directory contains synthetic educational CSV datasets used for customer cohort, retention, and profitability analysis:

- `Customer.csv`: Synthetic customer profiles and demographics (17,415 records).
- `EcomSales.csv`: Synthetic e-commerce transactional orders (51,290 records).
- `Product.csv`: Product catalog and category hierarchy (28,356 records).
- `Region.csv`: Geographic region mapping (3,828 records).

## Data Notice
Synthetic educational dataset. No real customer or confidential company data are included. These tables are provided for analytical demonstration and reproducibility.
